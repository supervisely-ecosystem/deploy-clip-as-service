GPU requirement: NVIDIA driver ≥ 550.163.01 (CUDA 12.8). CPU mode has no driver requirement. Both modes run in fp32. Versions up to 0.1.3 ran the GPU in fp16; vectors from those sessions differ from fp32 ones by ~1e-5 in cosine, which reshuffles only already-tied neighbours (measured: 1–2 changed top-1 hits per 200 queries) — mixing them in one collection is safe and no re-indexing is needed. If you specifically need the old fp16 GPU behaviour, run app version 0.1.3.
